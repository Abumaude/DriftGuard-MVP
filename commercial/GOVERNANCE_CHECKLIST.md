# Commercial Pre-Ship Governance Checklist

Use before publishing a material commercial asset.

This checklist does **not** replace specialist review skills. It routes the asset through the existing system.

## A. Buyer reality

- [ ] The asset addresses a real product/user problem, not an invented pain point.
- [ ] The intended buyer is identifiable.
- [ ] The product is not presented as appropriate for everyone.
- [ ] Required effort, prerequisites and dependencies are visible where material.

## B. Claims and evidence

- [ ] Every material factual claim has an Evidence Ledger entry.
- [ ] Claim wording does not exceed the evidence.
- [ ] Comparisons use a fair comparison basis.
- [ ] Numbers, testimonials and screenshots are authentic and scoped.
- [ ] Synthetic examples are labelled.

## C. Disclosure

- [ ] Material limitations appear before purchase.
- [ ] "Not for you" cases are real.
- [ ] The Honest Box includes weaknesses a fair competitor could exploit.
- [ ] Important exclusions are not buried in legal/FAQ copy.
- [ ] Free/cheaper alternatives are acknowledged when genuinely sufficient.

## D. Psychological mechanisms

- [ ] Pricing/anchoring is framing rather than deception.
- [ ] Scarcity or urgency maps to a real constraint.
- [ ] No fabricated popularity, countdown, stock, deadline or social proof.
- [ ] Fear/shame/confusion is not being exploited.
- [ ] Any mechanism flagged as SIMULATION has been rejected or separately justified.

## E. Fulfilment

- [ ] The delivery matches the promise.
- [ ] Onboarding reduces foreseeable failure.
- [ ] Refund/cancellation rules are visible and plain.
- [ ] Support expectations are clear.
- [ ] Product limitations in marketing match product documentation.

## F. Conflicts and provenance

- [ ] Internal review is not described as independent assurance.
- [ ] External attestation, if claimed, is actually independent.
- [ ] Sources and derivations are preserved.
- [ ] AI-generated assertions have been checked where material.

## G. Long-horizon test

- [ ] We would be comfortable showing this asset to a dissatisfied customer.
- [ ] We would be comfortable if a competitor quoted the claims verbatim.
- [ ] We would retain the same disclosure if it modestly reduced conversion.
- [ ] The asset creates trust even for a qualified person who decides not to buy.

## Route through existing skills when relevant

Recommended sequence for a material asset:

1. `challenge-the-brief`
2. `truth-engine-validation` or evidence review
3. `why-people-buy` / `instinct-map`
4. `efficiency-illusion-review`
5. `brand-review`
6. `writes-human` / `sounds-human`
7. final DriftGuard/decision-architecture gate

Do not build a new Governor agent merely to reproduce this sequence.
